## PROJECT ALMORA DEVELOPMENT

Always review the project documentation (`./docs`) and strictly follow all documented development rules, conventions, architecture, and coding standards.

Requirements:

- Follow industry-standard software engineering principles and best practices.
- Prioritize readability, maintainability, extensibility, and long-term scalability.
- Design for future extension while avoiding overengineering.
- Keep implementations modular, reusable, and loosely coupled.
- Maintain consistency with the existing project architecture, naming conventions, and coding style.
- Avoid unnecessary dependencies, abstractions, or complexity.
- Do not modify unrelated code.
- If documentation and code conflict, follow the documentation unless explicitly instructed otherwise.
- Do not use emojis, decorative formatting, or informal language. Maintain a professional and technical tone.
