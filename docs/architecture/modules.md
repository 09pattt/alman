# Module Breakdown

Detailed descriptions of each module inside `src/almora/`:

---

## 📦 Package Directory (`src/almora/`)

### 1. `core/`
Contains base configuration abstractions, settings management, and validation logic (`settings.py`).

### 2. `models/`
Defines core data models, types, and context objects.

### 3. `infrastructure/`
Contains external interaction implementations such as filesystem operations and local data storage.

### 4. `services/`
Houses application domain services and business workflow logic.

### 5. `app/`
Contains CLI interfaces and entry point handlers.

### 6. `utils/`
Helper functions and general data utilities used across packages.
